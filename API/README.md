# Pulse-Of-Life
A remote patient monitoring project that uses sensors to collect health data (such as blood pressure, heart rate, blood sugar, and cholesterol levels) to determine whether the individual has a heart condition. The system also enables users to book medical consultations and communicate with specialized physicians.

A brief note: This repository represents an updated and enhanced version of the project I originally completed on June 12, 2025, following a restructuring and code refinement process based on what I have learned over the past year.

# Pulse Of Life - Graduation Project (UI/UX Optimization & Code Refactoring)

## Project Overview
This repository contains the upgraded and optimized version of my graduation project. Built entirely using **Django, MySQL, and Bootstrap**, the project maintains its original core technology stack. However, the initial version developed a year ago featured a basic, unpolished user interface and disorganized frontend code.

To demonstrate my professional growth, I took the initiative to **completely refactor the frontend structure and overhaul the UI/UX**. Without changing the underlying framework, I redesigned the layout to be modern and highly responsive, optimized the user journeys, and organized the templates and custom scripts into a clean, maintainable structure.

---

## Project Evolution & Refactoring Breakdown

| Aspect | Legacy Version (Old) | Upgraded Version (New) |
| :--- | :--- | :--- |
| **UI/UX & Design** | Basic, rigid, and unpolished Bootstrap implementation | Modern, clean, and fluid UI layout with optimized user workflows |
| **Responsiveness** | Limited layouts with inconsistent mobile compatibility | Fully responsive and mobile-friendly layouts across all views |
| **Code Organization** | Disorganized Django templates with scattered JavaScript/jQuery scripts | Modular templates (`{% include %}` / blocks) and structured static assets |
| **Backend & Architecture** | Functional Django & MySQL core but lacked view optimization | Cleaned and optimized Django views, queries, and form handlings |
